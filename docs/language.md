# Мова SIPL, версія 1.0

Машинозчитувана граматика: [`src/sipl/grammar/sipl.lark`](../src/sipl/grammar/sipl.lark)
(Lark, LALR(1)). Цей документ описує її та фіксує рішення там, де курс залишає свободу.

## Лексика

| Клас | Вигляд |
|---|---|
| Ключові слова | `begin end if then else while do skip true false and or not` |
| Змінна | `[A-Za-z_][A-Za-z0-9_]*`, крім ключових слів; регістр має значення |
| Число | `[0-9]+` — невід'ємний цілий літерал |
| Присвоювання | `:=` |
| Арифметика | `+  -  *  /` (також `÷`) |
| Порівняння | `=`, `!=` (`<>`, `≠`), `<`, `<=` (`≤`), `>`, `>=` (`≥`) |
| Логіка | `and` (`&`, `∧`), `or` (`\|`, `∨`), `not` (`!`, `¬`) |
| Розділювачі | `;  (  )` |

Пробіли та переходи рядка ігноруються. Коментарів у мові немає: їх немає в БНФ курсу.
Ключові слова зарезервовані завжди, тож `begin end` є синтаксичною помилкою, а не блоком зі змінною `end`.

## Граматика

```ebnf
program     ::= stmt
stmt        ::= simple_stmt { ";" simple_stmt }
simple_stmt ::= VAR ":=" aexpr
              | "if" bexpr "then" simple_stmt "else" simple_stmt
              | "while" bexpr "do" simple_stmt
              | "begin" stmt "end"
              | "skip"

aexpr  ::= aexpr ("+" | "-") term | term
term   ::= term ("*" | "/") factor | factor
factor ::= NUMBER | VAR | "(" aexpr ")"

bexpr   ::= bexpr "or" bterm | bterm
bterm   ::= bterm "and" bfactor | bfactor
bfactor ::= "not" bfactor | batom
batom   ::= "true" | "false" | aexpr REL aexpr | "(" bexpr ")"
```

### Відповідність БНФ курсу

БНФ курсу (`S ::= S ; S | ...`, `a ::= a + a | ...`) неоднозначна. Мова та сама, але граматику
розшаровано за пріоритетом, щоб кожна програма мала одне дерево виводу:

- `S1 ; S2 ; S3` розбирається як плоский список; в AST це вузол `Seq` з трьома елементами.
  Семантично це те саме, бо композиція асоціативна.
- `*`, `/` мають вищий пріоритет за `+`, `-`; усі чотири лівоасоціативні.
- `not` > `and` > `or`. Порівняння не асоціативні: `1 < 2 < 3` є помилкою.
- Гілки `if` і тіло `while` складаються з одного оператора. Кілька операторів беруться в
  `begin ... end`. Отже, `while b do S1; S2` означає `(while b do S1); S2`.
- `else` обов'язковий, як у БНФ курсу.
- Унарного мінуса немає. Від'ємне значення записується як `0 - 5` або передається у стан.

## Семантика

- **Стан** — часткове відображення «змінна → ціле число». Цілі необмежені (Python `int`).
- **Присвоювання** `x := a` обчислює `a` у поточному стані та оновлює `x`.
- **Невизначеність**. Результат програми не визначений, якщо:
  - змінну читають до присвоювання (`undefined-variable`);
  - відбувається ділення на нуль (`division-by-zero`).

  Інтерпретатор повідомляє про це помилкою з позицією в коді.
- **Ділення** цілочисельне з відкиданням дробової частини (до нуля): `-7 / 2 = -3`.
- **Логічні операції строгі**: обидва операнди обчислюються завжди, як у композиції
  семантичних функцій. `true or X > 0` невизначене, якщо `X` не задано.
- **Нетермінація**. Програма може не завершуватися, тому інтерпретатор обмежує кількість
  виконаних операторів (`--max-steps`, за замовчуванням 100 000) і повідомляє `step-limit`.
  Це обмеження інструмента, а не частина семантики.
- **Крок** — виконання одного вузла-оператора AST (`Assign`, `Seq`, `If`, `While`,
  `Block`, `Skip`).
